# fw-practice

A small C project for learning agent skills, MCP and the firmware kit safely.
Follow the learning guide; start with lesson 0.

- `src/`, `tests/`   a ring buffer and one test
- `scripts/`         build, test, lint and size scripts that stand in for a real toolchain;
                     `flash.sh` only prints a message and must never be run by an agent
- `gen/`             pretend generated code that must never be edited
- `solutions/`       finished files for lessons 5, 6, 9, 10 and 11. Try first, then compare.
